0 ≤
x ≤9.  Domain dari jumlah bahan bakar yang dinyatakan dalam himpunan 
adalah { x | 0 ≤x ≤9, x ∈R }, dengan R merupakan himpunan bilangan riil.
Domain ini dapat juga dituliskan dalam bentuk [0,9].  
Jarak tempuh dituliskan sebagai 0 ≤y ≤250. Range dari jarak tempuh 
adalah { y|0 ≤y ≤250, y ∈R }, dengan R merupakan himpunan bilangan bulat 
positif. Range dapat juga dituliskan dalam bentuk [0,250].
